# HTS-UI

#### Description
HTS UI 是 HTS工作室全站统一使用的界面规范实现。设计原则只有一条：**只用黑白灰，拒绝一切渐变与花哨特效**——纯色、细边框、15px 圆角、0.25s 缓动，所有颜色通过 CSS 变量定义，深色模式只需覆盖变量，组件样式永远只写一份
